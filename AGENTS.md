# AGENTS.md - Persistent Rules and Instructions

## ⚠️ CRITICAL: DO NOT MODIFY OR OVERWRITE APP ICONS
- **DO NOT** delete, modify, or overwrite `ic_launcher_foreground.png` or `ic_launcher_background.png` in `/app/src/main/res/drawable/` or any mipmap folders.
- These files contain the user's custom-uploaded app icons (`icon_foreground.png` and `icon_background.png`).
- Under no circumstances should these PNG assets be replaced by generated SVG/XML vectors or default placeholder icons.
- Always preserve the user's custom-designed icon files during any build, cleanup, or refactoring task.
